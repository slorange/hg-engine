# Local scripts (not tracked)

Throwaway recon, one-off debugging, and session experiments live here. **Do not commit** contents of this folder.

When a script becomes reusable (referenced from `documentation/HACK-NOTES.md` or wired into `Makefile` / `narcs.mk`), move it to `scripts/dev/` or `scripts/build/`.

See `documentation/HACK-NOTES.md` § **Scripts layout**.
